### Public code

- [lectern](https://github.com/calumhrmurray/lectern) is a visual editor for the slides an
  AI assistant writes. You ask for a talk, it writes the reveal.js file, and you move things
  around on a canvas while it carries on with the content. It's on npm as `lectern-editor`.
- [capish](https://github.com/calumhrmurray/capish) does cluster cosmology by
  likelihood-free inference, written with Constantin Payerne. It forward models a whole
  cluster survey, from cosmological parameters through to the summary statistics you would
  actually measure, with the selection and the measurement errors in between.
- [This pull request](https://github.com/adematti/cucount/pull/1) added correlations of
  arbitrary spin quantities to Arnaud de Mattia's GPU pair counting code. That's what you
  need to correlate galaxy shapes with galaxy positions, and it runs about a hundred times
  faster than the CPU codes I was using.
